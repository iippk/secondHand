## 1. 测试概述

### 1.1 测试目标
确保校园二手物品交易平台的各个功能模块能够正常工作，系统性能满足要求，数据安全可靠，用户体验良好。

### 1.2 测试范围
- 单元测试：各个微服务的核心功能和组件
- 集成测试：服务间交互和数据流
- 接口测试：RESTful API接口的正确性和性能
- 前端测试：页面功能和用户交互
- 性能测试：系统响应时间和并发处理能力
- 安全测试：认证、授权和数据安全

### 1.3 测试工具
- **单元测试框架**：JUnit 5
- **Mock工具**：Mockito
- **API测试工具**：Postman、REST Assured
- **前端测试工具**：Jest、Vue Test Utils
- **性能测试工具**：JMeter、Gatling
- **持续集成工具**：Jenkins

        String token = loginResponse.getBody().getData().getToken();
        
        // 3. 创建订单
        HttpHeaders headers = new HttpHeaders();
        headers.set("Authorization", "Bearer " + token);
        headers.setContentType(MediaType.APPLICATION_JSON);
        
        OrderCreateRequest orderRequest = new OrderCreateRequest();
        orderRequest.setProductId(product.getId());
        orderRequest.setPrice(new BigDecimal(100));
        orderRequest.setTradeType(1);
        
        HttpEntity<OrderCreateRequest> orderEntity = new HttpEntity<>(orderRequest, headers);
        ResponseEntity<ApiResponse<Order>> orderResponse = 
                restTemplate.postForEntity("/api/v1/orders", orderEntity, 
                        new ParameterizedTypeReference<ApiResponse<Order>>() {});
        
        // 4. 验证订单创建成功
        assertEquals(HttpStatus.OK, orderResponse.getStatusCode());
        Order order = orderResponse.getBody().getData();
        assertNotNull(order);
        assertEquals(buyer.getId(), order.getUserId());
        assertEquals(seller.getId(), order.getSellerId());
        assertEquals(product.getId(), order.getProductId());

        HttpEntity<OrderStatusRequest> statusEntity = new HttpEntity<>(statusRequest, headers);

                        new ParameterizedTypeReference<ApiResponse<Boolean>>() {});

        // 7. 从数据库查询验证

        assertEquals(1, dbOrder.getStatus()); // 待发货
    }

@SpringBootTest(webEnvironment = WebEnvironment.DEFINED_PORT)
public class ProductApiTest {

    private String token;
    
    @BeforeEach
    public void setup() {
        RestAssured.baseURI = "http://localhost:8080";
        
        // 登录获取token
        String loginBody = "{\"username\":\"producttest\",\"password\":\"password123\"}";
        
        Response response = given()
            .contentType(ContentType.JSON)
            .body(loginBody)
        .when()
            .post("/api/v1/users/login");
        
        token = response.jsonPath().getString("data.token");
    }
    
    @Test
    public void testProductCrudApi() {
        // 1. 创建商品
        String createBody = "{\"title\":\"API测试商品\",\"description\":\"测试描述\",\"price\":199.99,\"categoryId\":1}";
        
        Response createResponse = given()
            .contentType(ContentType.JSON)
            .header("Authorization", "Bearer " + token)
            .body(createBody)
        .when()
            .post("/api/v1/products");
        
        createResponse.then()
            .statusCode(200)
            .body("code", equalTo(200));
        
        Long productId = createResponse.jsonPath().getLong("data.id");
        assertNotNull(productId);
        
        // 2. 查询商品详情
        given()
            .header("Authorization", "Bearer " + token)
        .when()
            .get("/api/v1/products/" + productId)
        .then()
            .statusCode(200)
            .body("data.id", equalTo(productId.intValue()))
            .body("data.title", equalTo("API测试商品"));

        given()
            .contentType(ContentType.JSON)
            .header("Authorization", "Bearer " + token)

import io.gatling.core.Predef._
import io.gatling.http.Predef._
import scala.concurrent.duration._

class ProductSearchSimulation extends Simulation {

    .baseUrl("http://localhost:8080")
    .acceptHeader("application/json")
    .userAgentHeader("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36")

    .exec(
      http("首页访问")
        .get("/")
        .check(status.is(200))
    )
    .pause(1)
    .repeat(10) {
      exec(
        http("搜索商品")
          .get("/api/v1/search/products?keyword=${keyword}&page=1&size=10")
          .check(status.is(200))
          .check(jsonPath("$.code").is("200"))
      )
      .pause(2)
    }
  
  setUp(
    scn.inject(
      rampUsers(100).during(30.seconds),
      constantUsersPerSec(50).during(2.minutes),
      rampUsers(200).during(30.seconds),
      constantUsersPerSec(100).during(2.minutes)
    ).protocols(httpProtocol)
  ).assertions(
    global.responseTime.mean.lt(500),

            .header("Authorization", "Bearer invalid-token")
        .when()
            .get("/api/v1/users/info")
        .then()

            .body("code", equalTo(401))
            .body("message", equalTo("无效的认证信息"));

    @Test
    public void testAccessDenied() {
        // 创建两个用户并分别登录
        String user1Token = login("user1", "password123");
        String user2Token = login("user2", "password123");
        
        // 用户1创建商品
        String productId = createProduct(user1Token);
        
        // 用户2尝试修改用户1的商品（权限测试）
        given()
            .contentType(ContentType.JSON)
            .header("Authorization", "Bearer " + user2Token)
            .body("{\"title\":\"尝试修改他人商品\"}")
        .when()
            .put("/api/v1/products/" + productId)
        .then()
            .statusCode(200)
            .body("code", equalTo(403))
            .body("message", equalTo("没有操作权限"));
    }
    
    private String login(String username, String password) {
        String loginBody = String.format("{\"username\":\"%s\",\"password\":\"%s\"}", username, password);
        
        Response response = given()
            .contentType(ContentType.JSON)
            .body(loginBody)
        .when()
            .post("/api/v1/users/login");
        
        return response.jsonPath().getString("data.token");
    }

            .contentType(ContentType.JSON)
            .header("Authorization", "Bearer " + token)

## 10. 测试策略总结

### 10.1 测试层次

1. **单元测试**：确保单个组件和函数的正确性
2. **集成测试**：验证组件间的交互是否正常
3. **API测试**：验证所有对外接口的功能和性能
4. **前端测试**：验证用户界面的功能和用户体验
5. **性能测试**：验证系统在高负载下的性能表现
6. **安全测试**：确保系统的安全性和数据保护

### 10.2 测试最佳实践

- **测试驱动开发(TDD)**：先编写测试用例，再编写实现代码
- **持续集成**：每次代码提交自动运行测试
- **自动化测试**：尽可能自动化测试流程，减少人工干预
- **测试数据隔离**：确保测试环境和生产环境数据隔离
- **测试覆盖率监控**：定期检查和提高测试覆盖率
- **性能基准测试**：建立性能基准，监控性能变化

### 10.3 测试风险控制

- **关键业务优先测试**：优先测试核心业务流程
- **边界值测试**：测试各种边界条件和异常情况
- **回归测试**：每次修改后运行回归测试，确保没有引入新的问题
- **模拟环境测试**：在模拟生产环境中进行测试
- **灾难恢复测试**：测试系统在故障情况下的恢复能力
